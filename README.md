# 🚆 Railway Ticketing App — Frontend

A Railway Ticketing Application frontend built with React.js and Vite, featuring a modern component-based architecture.

## 🚀 Features

- ⚛️ Component-based React architecture
- ⚡ Fast development with Vite + Hot Module Replacement (HMR)
- 🎨 Clean, responsive UI
- ✅ ESLint configured for code quality

## 🛠️ Tech Stack

`React.js` · `Vite` · `JavaScript` · `HTML` · `CSS` · `ESLint`

## ⚙️ Getting Started

```bash
# Clone the repository
git clone https://github.com/ArpitTiwari2001/RailwayTicketingAppFrontend.git
cd RailwayTicketingAppFrontend/first-app

# Install dependencies
npm install

# Start the development server
npm run dev

# Then open the local URL shown in your terminal
(usually) http://localhost:5173/
```
## 📦 Build for Production

```bash
npm run build
```
